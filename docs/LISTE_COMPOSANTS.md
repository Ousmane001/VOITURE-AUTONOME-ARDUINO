## Kits Complets (Alternative)

Plusieurs fabricants proposent des kits complets:
- **Elegoo Smart Robot Car Kit V4.0**: ~70-80€
- **SunFounder Smart Video Car**: ~80-100€
- **DFRobot Maqueen**: ~60-70€

**Avantages des kits**:
- Tous les composants inclus
- Châssis déjà assemblé
- Documentation fournie
- Prix global avantageux

**Inconvénients**:
- Moins de flexibilité
- Composants propriétaires parfois
- Apprentissage moins approfondi

## Notes d'Achat

1. **Vérifier la compatibilité** des tensions (5V pour Arduino)
2. **Privilégier les lots** pour réduire les coûts
3. **Prévoir des composants de rechange** (LED, résistances)
4. **Comparer les prix** entre fournisseurs
5. **Grouper les commandes** pour réduire les frais de port
6. **Choisir des fournisseurs européens** pour éviter les taxes douanières

## Évolution du Projet

### Phase 1 - MVP (Minimum Viable Product)
- Arduino Uno
- 1 capteur ultrasonique frontal
- 2 moteurs DC + L298N
- Châssis simple
- Batterie 4xAA

### Phase 2 - Standard
- 3 capteurs ultrasoniques
- Capteurs IR pour ligne
- Châssis optimisé
- Batterie Li-Po

### Phase 3 - Avancé
- Arduino Mega
- Capteurs additionnels
- Module communication
- Servo pour scan
- Caméra (Pixy2 ou similaire)
